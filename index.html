الزتونه

1️⃣ يعني إيه Front-end أصلاً؟

💡 الشرح بالبلدي:

تخيل إن الموقع ده عبارة عن "مطعم". الفرونت إند هو الديكور، الترابيزات، والمنيو اللي الزبون بيتعامل معاها.
يعني ببساطة: هو أي حاجة اليوزر بيشوفها بعينه وبيتفاعل معاها على الشاشة. وعلشان نبني الديكور ده بنحتاج 3 أساسيات لا غنى عنهم: HTML (للهيكل)، CSS (للديكور)، و JavaScript (للتفاعل).

🎯 سؤال من التسريبات:

❓ إيه اختصار كلمة HTML؟ مُسرب
اختصار لـ Hyper Text Markup Language. (وهي لغة هيكلة وتوصيف مش لغة برمجة، يعني مفيهاش شروط ولا Loops).

2️⃣ الـ HTML (الهيكل العظمي)

💡 الشرح بالبلدي:

الـ HTML هي طوب العمارة قبل المحارة. بيها بنقول للبراوزر: "حط هنا صورة"، "ده عنوان كبير"، "ده زرار". من غيرها مفيش صفحة ويب أصلاً.

🎯 تسريبات وأسئلة أساسية:

❓ إيه الفرق بين id و class؟ مُسرب
الـ id لازم يكون فريد (Unique) لعنصر واحد بس في الصفحة (زي رقم البطاقة). لكن الـ class ممكن أديه لأكتر من عنصر عشان أنسقهم كلهم بنفس الشكل في الـ CSS.

📚 بنك أسئلة HTML السريعة:

1. الفرق بين HTML4 و HTML5؟
HTML5 أضافت تاجات جديدة للفيديو والصوت (audio/video)، وتاجات الـ Semantic (header/footer)، ودعم أفضل للموبايل.
2. إيه هي الـ Semantic Tags؟
تاجات ليها معنى بتشرح محتواها للبراوزر ومحركات البحث (زي article, nav, header, footer) بدل استخدام div العادي.
3. الفرق بين div و span؟
div بياخد سطر كامل (Block-level)، لكن span بياخد مساحة الكلمة بس وبييجي جنب عناصر تانية (Inline).
4. إيه فايدة الـ DOCTYPE؟
بيعرف البراوزر إصدار الـ HTML المُستخدم في الصفحة (حالياً `` يعني HTML5).
5. إيه هي الـ Meta Tags؟
بيانات عن الصفحة (metadata) بتتحط في الـ head، مهمة جداً لمحركات البحث (SEO) وتظبط الشاشة عالموبايل (viewport).
6. الفرق بين GET و POST في الـ Forms؟
GET بيبعت الداتا مكشوفة في الـ URL (محدودة الحجم). POST بيبعت الداتا متخفية في الـ Body (آمنة وأكبر للحجم).
7. إيه هي الـ Void Elements؟
عناصر ملهاش قفلة (Closing Tag) زي `
`, ``, `
`, ``.
8. إيه فايدة الـ alt attribute في الصور؟
نص بديل بيظهر لو الصورة محملتش، ومهم جداً لقارئات الشاشة (Accessibility) للمكفوفين وللـ SEO.

3️⃣ الـ CSS (الدهان والشياكة)

💡 الشرح بالبلدي:

بييجي دور الـ CSS عشان يعمل المحارة والدهان والألوان، يظبط المسافات، ويخلي الموقع "ريسبونسف" (شكله حلو على اللاب والموبايل).

🎯 أسئلة حقيقية من جروبات الدفعة:

❓ الفرق بين absolute و relative في الـ Position؟ مُسرب
Relative: بيتحرك بالنسبة لمكانه الأصلي (ومكانه بيفضل محجوز).
Absolute: بيشيل العنصر من مسار الصفحة وبيتحرك بالنسبة لأقرب أب واخد Position.
❓ إيه الفرق بين inline و inline-block؟ مُسرب
الاتنين بيجوا جنب بعض. بس الـ inline مابيقبلش مقاسات (width/height). أما الـ inline-block بيقبل مقاسات عادي.

📚 بنك أسئلة CSS السريعة:

1. إيه هو الـ CSS Box Model؟
أي عنصر هو صندوق مكون من: المحتوى -> Padding -> Border -> Margin.
2. الفرق بين margin و padding؟
Padding هي المسافة الداخلية بين المحتوى وحدود العنصر. Margin هي المسافة الخارجية بتبعد العنصر عن جيرانه.
3. الفرق بين Flexbox و CSS Grid؟
Flexbox بيقسم العناصر في اتجاه واحد (صف أو عمود). Grid بيقسم العناصر في اتجاهين (صفوف وأعمدة مع بعض).
4. إيه هو الـ z-index؟
بيتحكم في ترتيب الطبقات (العناصر اللي فوق بعض). الرقم الأكبر بيغطي الأصغر.
5. إيه هي الـ Media Query؟
أداة بتخلينا نغير الـ CSS بناءً على مقاس الشاشة (عشان نعمل الـ Responsive Design).
6. الفرق بين visibility: hidden و display: none؟
visibility بيخفي العنصر بس بيسيب مكانه فاضي. display بيشيل العنصر خالص كأنه مش موجود.
7. إيه هي الـ SCSS/SASS؟
لغات بتخلينا نكتب CSS بطريقة برمجية (فيها متغيرات، دمج، Loops) وبعدين تتحول لـ CSS عادي.

4️⃣ الـ JavaScript (الروح) - الجزء الأول

💡 الشرح بالبلدي:

الموقع من غير JS زي المطعم من غير جرسون بياخد الأوردرات. الـ JS هي لغة البرمجة اللي بتخلي الموقع يتفاعل مع اليوزر. ودي أهم حاجة في الإنترفيو لأن المنحة كلها مبنية عليها!

🎯 أسئلة حقيقية (أكتر جزء بيتسأل فيه):

❓ إيه الفرق بين let, var, و const؟ مُسرب
var: قديمة ومشاكلها كتير (Function Scope).
let: قيمتها ممكن تتغير (Block Scope).
const: للثوابت اللي قيمتها مش هتتغير خالص.
❓ إيه هو الـ DOM؟ مُسرب
Document Object Model. البراوزر بيحول الـ HTML لشجرة (كائنات)، والـ JS بتقدر تمسك فروع الشجرة دي عشان تعدل الصفحة.

📚 بنك أسئلة JS السريعة (1):

1. إيه هي أنواع البيانات (Data Types)؟
أساسية (String, Number, Boolean, Undefined, Null). ومركبة (Object, Array).
2. الفرق بين null و undefined؟
undefined: متغير اتعمل بس لسه مخدش قيمة. null: إنت قاصد تخليه "فاضي".
3. إيه هو الـ Hoisting؟
سلوك بيرفع الـ Declarations (التعريفات بتاعة المتغيرات والدوال) لأعلى الملف قبل التشغيل (بيشتغل مع var).
4. إيه هو الـ Closure؟
لما دالة تبقى جوه دالة، الدالة الداخلية بتفضل شايفة متغيرات الدالة الخارجية حتى بعد ما الخارجية تخلص.
5. إيه هو الـ Callback Function؟
دالة بتتبعت جوه دالة تانية كـ Parameter، عشان تشتغل بعد ما الدالة الأساسية تخلص.
6. الفرق بين == و ===؟
`==` بتقارن القيمة بس. `===` بتقارن القيمة والنوع (ودي الأفضل).

4️⃣ الـ JavaScript - الجزء التاني

🎯 أسئلة حقيقية (تكملة الـ Arrays):

❓ إيه الفرق بين push, pop, shift, unshift؟ مُسرب
بيتعاملوا مع الـ Arrays:
push: بيضيف في الآخِر. pop: بيمسح من الآخِر.
unshift: بيضيف في الأول. shift: بيمسح من الأول.
❓ إيه الفرق بين slice و splice؟ مُسرب
slice: بتاخد "نسخة" من جزء من الـ Array ومابتأثرش ع الأصل. splice: بتقطع وتعدل في الـ Array الأصلية نفسها.

📚 بنك أسئلة JS السريعة (2):

7. الفرق بين Sync و Async؟
Sync بينفذ سطر سطر ويستنى. Async بيخلي العمليات الطويلة تشتغل في الخلفية من غير ما يوقف الموقع.
8. إيه هو Promise؟
وعد بإن عملية Async هتخلص. ليها 3 حالات: Pending (لسه)، Fulfilled (نجحت)، Rejected (فشلت).
9. إيه هما async و await؟
طريقة حديثة لترتيب الـ Promises، بتخلي كود الـ Async يتكتب ويتقرأ كأنه Sync عادي.
10. الفرق بين map, filter, reduce؟
map: بتعدل وترجع Array جديدة. filter: بترجع العناصر اللي نجحت في الشرط. reduce: بتجمعناصر الـ Array في قيمة واحدة.
11. الفرق بين Spread و Rest Operator (...)؟
Spread: بيفرد عناصر الـ Array `[...arr]`. Rest: بيلم العناصر المتبقية ويحطها في Array.
12. إيه هي الـ Arrow Function؟
طريقة مختصرة `() => {}` وميزتها إن ملهاش `this` خاصة بيها، بتاخد الـ this من اللي براها.
13. إيه هي الـ Truthy و Falsy Values؟
الـ Falsy هي: (0, "", null, undefined, NaN, false). أي حاجة تانية بتعتبر Truthy في الشروط.
14. الفرق بين localStorage و sessionStorage؟
localStorage بياناتها مابتتمسحش لو قفلت البراوزر. sessionStorage بتتمسح أول ما تقفل الـ Tab.

5️⃣ صورة عامة للـ Frameworks

💡 الشرح بالبلدي (نظرة عامة):

عشان نعمل موقع كبير مش بنكتب كود من الصفر (Vanilla JS)، بنستخدم أُطر عمل (Frameworks/Libraries) بتسهل علينا.

بالنسبة للفرونت إند (Front-end)، السوق فيه 3 وحوش كبار:

  • React: مكتبة من (فيسبوك)، مرنة جداً ومشهورة أوي بس بتخليك تعتمد على مكاتب خارجية كتير.
  • Vue.js: خفيف جداً وسهل في التعلم، واخد حلاوة الرياكت والأنجولار.
  • Angular: من (جوجل)، فريم وورك "متكامل"، فيه كل حاجة جواه، منظم جداً للشركات الكبيرة (وده اللي هندرسه في المنحة).

6️⃣ الباك إند وتراك الـ MEAN

💡 الشرح بالبلدي (لغات الباك إند):

الباك إند هو "مطبخ المطعم"، اللي بيكلم الداتا بيز. زمان كان لازم نكتبه بلغات مختلفة زي:

  • PHP: لغة قديمة ومشهورة جداً (شغال بيها ووردبريس).
  • Python: لغة قوية في التعامل مع الداتا والذكاء الاصطناعي (Django/Flask).
  • Java / C#: للأنظمة البنكية والشركات الضخمة.

بس إحنا في تراك (MEAN) بنعمل اختراع!

بنستخدم Node.js، وده بيخلينا نكتب المطبخ (الباك إند) بنفس لغة الفرونت إند (JavaScript)، فالمبرمج بيبقى فول ستاك بلغة واحدة بس.

الـ MEAN اختصار لـ: MongoDB (الداتا بيز) + Express (لتسهيل الباك) + Angular (للفرونت) + Node.js (بيئة التشغيل).

7️⃣ الداتا بيز (MongoDB) و الـ OOP

💡 الشرح بالبلدي:

MongoDB قاعدة بيانات NoSQL ذكية جداً ومرنة، بتحفظ الداتا كأنها ملفات (JSON Documents) مش في جداول (Tables) معقدة زي قواعد بيانات الـ SQL القديمة.

🎯 أسئلة الإنترفيو المتسربة:

❓ اتسألت في الـ OOP، يعني إيه؟ مُسرب
Object-Oriented Programming (البرمجة الكائنية): بنظم كودي في شكل (Classes) و (Objects) عشان ماكررش الكود. أهم مبادئها: الوراثة (Inheritance)، التغليف (Encapsulation)، وتعدد الأشكال (Polymorphism). ومهمة جداً عشان Angular بيشتغل بـ TypeScript المبنية ع الـ OOP.

8️⃣ الأمان والأداء (مستوى متقدم)

🎯 أسئلة الإنترفيو المتقدمة:

❓ إزاي بتأمن الأبلكيشن بتاعك؟ (Security)
بشفر الباسوردات بـمكتبة (Bcrypt) في Node.js، وبستخدم JWT Token عشان أخلي الـ Login آمن، ولازم أعمل Validation (تأكيد صحة الداتا) في الفرونت والباك عشان أمنع أي محاولة هاكينج.
❓ إزاي نعالج مشكلة بطء السيرفر (Node.js) وقت الضغط العالي؟
عن طريق استخدام Caching (تخزين مؤقت) زي Redis عشان نحفظ الداتا المتكررة بدل ما نكلم الداتابيز كل شوية، وممكن نعمل Load Balancing لتوزيع الضغط على كذا سيرفر.
❓ إزاي بتعالج الـ Performance في Angular؟
باستخدام الـ Lazy Loading (تحميل صفحات الموقع وقت الحاجة ليها بس مش كلها مرة واحدة) وضبط استراتيجية الـ Change Detection.
